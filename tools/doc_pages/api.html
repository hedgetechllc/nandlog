API Reference

Everything in nandlog.h. Include that one header.

Every public function takes an internal lock for its whole duration, so a caller never holds one and calls never nest. All of them are safe to call from any thread provided your port supplies a real mutex.

Lifecycle

bool nandlog_probe(void);

Confirm a part is present and answering, without bringing the log up or writing anything. Intended for builds that only test for its presence; nandlog_init() performs the same check for itself.

bool nandlog_init(void);

Bring the log up: open the port, identify the part, load its bad-block table, recover the current epoch from the metadata ring, and locate the write head within it. Safe to call more than once.

Returns false if the port could not be opened or the part did not answer. No other call should be made in that case.

void nandlog_deinit(void);

Release the port. The log can be brought back up with nandlog_init().

void nandlog_disable(bool disable);

Stop or resume accepting records. A disabled log discards what it is given rather than buffering it, and still serves reads. Nothing is disabled by nandlog_init().

uint32_t nandlog_data_bytes_per_page(void);

Payload bytes a page can carry on the fitted part: the page size less the header the log writes into it. Answered from the chip driver, so it is correct before nandlog_init() has run.

Sessions

A session holds the part powered across a run of operations instead of waking and sleeping it around each one. Epoch operations and reads require one; ordinary logging does not. Sessions do not nest.

void nandlog_begin_session(void);
void nandlog_end_session(void);

Open and close a session. Ending one implies nandlog_end_reading() and returns the read view to the current epoch.

Epochs

An epoch is one generation of the log: a numbered run with its own start page and its own sequence numbering from zero. Reads cover one epoch at a time.

bool nandlog_begin_epoch(const void *blob, uint16_t length);

Begin a new epoch, described by an opaque caller-defined blob of at most NANDLOG_MAX_EPOCH_DETAILS_BYTES. The log neither reads nor interprets the blob. Everything logged previously stays on the part but stops being reachable through nandlog_begin_reading(), since reads cover the current epoch unless told otherwise.

Requires a session. Returns false if there is no session, if the blob is too large, or if no slot in the metadata ring would take it.

void nandlog_retrieve_epoch_details(void *blob, uint16_t length);

Copy back the details of whichever epoch is selected, truncated to length. Zero-fills if there are none, so a caller that never stored any reads zeros rather than stale bytes.

Reading an earlier epoch

An earlier epoch is not preserved, only left alone. The write head sweeps forward from where the previous generation stopped and erases each block just before it needs it, so an epoch is eaten from its start as the current one grows. What comes back is whatever is left; a page that has been swept over reads as a gap exactly like one that rotted.

uint32_t nandlog_epoch_count(void);

How many epochs the metadata ring still describes, the current one included, capped at NANDLOG_MAX_LISTED_EPOCHS (16). Costs one pass over the ring, reading a header per slot. Nothing is cached between calls.

bool nandlog_epoch_info(uint32_t index, nandlog_epoch_info_t *info);

Describe the index-th epoch, newest first, so index 0 is always the current one. Returns false once the index runs past what the ring describes.

typedef struct
{
   uint32_t epoch;               /* the generation number                        */
   uint32_t created_timestamp;   /* whatever the caller stamped                  */
   uint32_t first_page;          /* physical page its sequence 0 was written to  */
   uint16_t details_length;      /* bytes of caller-defined details in its slot  */
   bool     is_current;          /* whether this is the epoch being written now  */
} nandlog_epoch_info_t;
bool nandlog_select_epoch(uint32_t epoch);
void nandlog_select_current_epoch(void);

Point reads at an epoch other than the one being written, and back again. Writing is refused while an earlier epoch is selected, so a download cannot be mistaken for somewhere to put data.

nandlog_select_epoch() requires a session, fails while a read is open, and returns false if no slot in the ring names that epoch. Ending the session also returns to the current epoch.

A read that yields nothing means the epoch has been overwritten, not that it never existed — compare against nandlog_epoch_info(), which still describes it from the ring.

nandlog_begin_session();

for (uint32_t i = 0; i < nandlog_epoch_count(); ++i)
{
   nandlog_epoch_info_t info;
   if (nandlog_epoch_info(i, &info))
      printf("epoch %u%s\n", info.epoch, info.is_current ? " (current)" : "");
}

if (nandlog_select_epoch(previous))
{
   nandlog_retrieve_epoch_details(&details, sizeof(details));
   nandlog_begin_reading(0, 0);
   /* ... the usual read loop ... */
   nandlog_end_reading();
}

nandlog_end_session();

Writing

void nandlog_store_record(uint8_t record_type, uint32_t timestamp,
                          const void *data, uint32_t data_length);

Append one record to the page being assembled in RAM. record_type and data are opaque to the log; the timestamp is only ever compared, never interpreted, so its epoch and units are yours.

A timestamp may be earlier than records already in the page by up to NANDLOG_TIMESTAMP_TOLERANCE_MS, as when one record is stamped when something starts and stored after another writer's record that was stamped later. It is kept exactly as given, and the page's bounds widen to cover it, so a page is not necessarily in time order. A larger backward step means the time base moved, and commits the page first.

Committing a full page happens here, so this call occasionally writes to flash. Records are never split across pages, and one larger than a page is dropped — check nandlog_data_bytes_per_page() if your records are large.

With NANDLOG_RECORD_FRAMING on, the record is prefixed with its own data length, costing two bytes.

void nandlog_flush(bool write_partial_pages);

Commit what is buffered. A page is written automatically as soon as the next record will not fit, so this is only needed to force out a partial page — a timed flush, or shutdown. Pass false to write only if a whole page has accumulated.

bool nandlog_has_buffered_data(void);

Whether any records are sitting unwritten in RAM.

Reading

void nandlog_begin_reading(uint32_t starting_timestamp, uint32_t ending_timestamp);

Open a read over the selected epoch, bounded by timestamp. Zero for either bound means "from the beginning" and "to the end"; both bounds are resolved here, so nothing downstream has to seek again. Both err outward — a little extra data to filter beats dropping data that was asked for. A window with nothing logged inside it, such as one falling between two runs, selects nothing.

Requires a session. While a read is open, writing is refused.

void nandlog_end_reading(void);

Close a read, whether or not it ran to completion. Implied by nandlog_end_session().

void nandlog_read_span(uint32_t *num_pages, uint32_t *num_bytes);

Measure the open read: how many pages it will yield, including any that turn out to be unreadable, and how many payload bytes they hold. Either pointer may be NULL. Reports zero for both if no read is open.

The byte total is exact in both directions — it verifies payload CRCs as well as headers, so a page with a sound header and a rotted payload is not counted and then not delivered. A host sizing a receive buffer depends on that.

The byte total costs a read of every page in the span, doubling the flash traffic of a download. Pass NULL unless the figure is needed exactly; the page count is arithmetic.

uint32_t nandlog_retrieve_next_page(uint8_t *buffer, nandlog_page_header_t *header);

Take the next page of the open read, returning its payload length. Pass NULL for header to ignore the framing metadata.

Zero means that page was unreadable, which is not the end of the read. A page whose header could not be read comes back with seq set to its position, so the gap is still identifiable.

uint32_t nandlog_retrieve_page_by_seq(uint32_t seq, uint8_t *buffer,
                                     nandlog_page_header_t *header);

Fetch one page of the selected epoch by its sequence number, so a host can re-request what it lost. Returns zero, with the header describing the gap, if that page cannot be produced.

uint32_t nandlog_read_recent_page(uint32_t pages_back, uint8_t *buffer,
                                  nandlog_page_header_t *header, bool *end_of_epoch);

Walk backwards from the write head, newest page first, independently of any open read and without needing a session. Zero means that page could not be read, which is not the end of the log; end_of_epoch is the signal to stop.

bool nandlog_framed_next_record(const uint8_t *payload, uint32_t length, uint32_t *offset,
                                const uint8_t **record, uint32_t *record_bytes);

Step through the records of a payload belonging to a page that announced NANDLOG_PAGE_MAGIC_FRAMED. Initialise *offset to zero and call until it returns false. *record points at [type:1][timestamp:4][data].

Retransmission

Sequence numbers are contiguous within an epoch, so a host knows exactly which pages it is missing.

void nandlog_retransmit_clear(void);
uint32_t nandlog_retransmit_add(const uint32_t *seqs, uint32_t count);
uint32_t nandlog_retransmit_count(void);

Accumulate the sequence numbers a host reports missing, across as many calls as it takes. nandlog_retransmit_add() returns the number held; anything beyond NANDLOG_MAX_RETRANSMIT_PAGES (256) is dropped.

uint32_t nandlog_retransmit_total_bytes(void);

Exact total of the payload bytes the requested pages will deliver, for a host sizing a receive buffer. Costs a read of each requested page.

uint32_t nandlog_retrieve_retransmit_page(uint32_t index, uint8_t *buffer,
                                          nandlog_page_header_t *header);

Serve the index-th requested page. An index past the end yields a zero-length page rather than nothing, so the host can tell "still missing" from "never answered".

Diagnostics

uint32_t nandlog_bad_block_count(void);

How many blocks across the metadata ring and the log region are retired, factory-marked and grown alike. Answers from RAM: the figure is recomputed when the log comes up and whenever a block is retired, so reading it is free.

Useful as a health indicator over a part's life. A count that climbs steadily is a part approaching the end of its endurance; a count that jumps is worth investigating.

Recovery

void nandlog_reset_bad_block_table(void);

Discard the persisted bad-block table so it is rebuilt from the factory markers on the next boot. What this can achieve depends on the part: one that remaps in hardware cannot forget. The outcome is reported through nandlog_port_log().

Version macros

#define NANDLOG_VERSION_MAJOR    1
#define NANDLOG_VERSION_MINOR    2

#define NANDLOG_VERSION_AT_LEAST(major, minor)   /* ... */

Major changes when something you built against must change — a structure that moves on flash or on the wire, a function that is renamed or whose meaning shifts. Minor changes for additions. NANDLOG_FORMAT_VERSION is separate and versions the record grammar a particular build writes; see On-Flash Format.
